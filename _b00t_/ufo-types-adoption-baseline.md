### ufo-types modules available but not yet measured above

ufo-types (github.com/PromptExecution/ufo-types) ships several modules
this repo does not yet consume, at least as of the pinned version in the
workspace root `Cargo.toml`:

- `capability` — `AgentCapability`, `CapabilityDomain`, `ActionRecord`, `StateObservation`
- `dare` — `DaredProposal`, `DaredDocument`, `DaredAcceptanceCriteria`
- `iso` — `IsoAuditable`, `Iso4217`, `Lei`
- `stereotype`/`ooda` surface — `OodaStateMachine`, `OodaPhase`, `OodaEvent`

That unused surface is what #907 (blessing manifests via `capability`),
#908 (OODA control plane via `dare`), and #909 (agent introspection types)
each propose adopting — this doc is their shared prerequisite. Unlike the
table below, this module list is not independently grepped from an
external repo checkout (ufo-types is a git dependency, not vendored in
this tree) — treat it as informational context, not a measured metric.
