# Session Takeaways — 2026-06-29/30

## MCP Server Compatibility
- **opencode Zod validator**: tools MUST have `description`. `inputSchema` MUST have `type: "object"`. Strip `$schema` from inputSchema. `oneOf`-only schemas rejected.
- **Protocol version**: server MUST respond with client's version (opencode = 2024-11-05). Newer versions cause silent failure.
- **b00t schema**: `[[b00t.gate.check]]` → `[[b00t.gate]]`. `[[b00t.env]]` → `[[b00t.gate]]` with `env` field. Old `[mcp]` format → `[[b00t.mcp.stdio]]`.
- **async-openai**: hangs on custom HTTP endpoints. Use raw `reqwest` for embedding calls. Connection pooling under concurrency is the culprit.

## Knowledge Graph
- **67K nodes, 127K edges**: MCP queries time out (5s default). Use CLI mode: `codebase-memory-mcp cli query_graph`.
- **Edge type filtering broken**: `type(r)` returns nothing. `MATCH (n)-[:CALLS]-()` returns 0. Connectivity check works but type-scoped queries don't.
- **No isolated nodes**: `OPTIONAL MATCH (n)-[r]-() WHERE count(r) = 0` returns 0. Graph is fully connected. Viz may show "isolated" nodes that only have DEFINES edges (not CALLS/USAGE).

## Submodules

## Architecture
- **SemanticClass**: 9 classes provide shape/color/icon defaults. 26 DatumType variants each pick one class. `css_class` is the subsystem animation hook.
- **b00t sh**: guard-enforced sandboxed shell. All system mutations through the guard pipeline.
- **blessed ecosystem**: blessed.rs → TOML manifest → `blessed-query` tool. Trust tiers: blessed > awesome > local.
- **rust-doc MCP**: needs embeddings API (OPENAI_API_BASE + OPENAI_API_KEY + EMBEDDING_MODEL). Must set `EMBEDDING_MODEL=nomic-embed-text` for local k8s endpoint.
