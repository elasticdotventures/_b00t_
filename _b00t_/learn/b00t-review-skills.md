# b00t Review Skills

For b00t-owned Rust pipeline review, load b00t role context plus relevant b00t skills before design or critique.

Useful baseline for this slice:
- `b00t whoami --role=operator --skills=auto`
- `b00t learn rust`
- `b00t learn agent-orchestration`
- `b00t learn systematic-debugging`

Generic context-free Rust review drifts away from b00t stereotype/capability style and should be treated as weak evidence.
