Root cause: /usr/share/containers/oci/hooks.d/oci-nvidia-hook.json matches every container unconditionally (when.always=true) and this legacy hook fails outright under rootless podman, almost certainly because no-cgroups is not set to true in /etc/nvidia-container-runtime/config.toml (a documented rootless-podman requirement) -- needs root to fix, not yet done. WORKAROUND that actually works: skip podman kube play entirely for GPU workloads, use plain 'podman run --device nvidia.com/gpu=all ...' instead -- pure CDI device injection resolved directly by podman, does not invoke the hooks.d prestart hook at all. Also: the ghcr.io/ggml-org/llama.cpp:server-cuda image has a baked-in HEALTHCHECK hardcoded to port 8080; if you run the server on a different --port (e.g. 8001), podman will report the container unhealthy forever even though it works -- fix with 'podman update --health-cmd "curl -f http://localhost:<real-port>/health" <container>' after starting it. <!-- salvaged:topic_overflow -->
