irontology backend needs HelixDB running: 'grok ask' without --rag=raglite always tries irontology, which calls a HelixDB graph server at http://localhost:6969/v1/query. If nothing is listening there (no local HelixDB/irontology-mcp instance up), every irontology-backed grok ask AND grok digest/lfmf-store call fails silently with a warning, not a hard error -- results just come back empty. Check 'curl -s localhost:6969/v1/query' or start irontology-mcp before trusting a 'no results' answer. Pass --rag=raglite --topic <t> to skip irontology entirely for a quick keyword-only check.
