## User Preferences & Meta-Patterns

1. **No TOML bloat**: Display properties are Rust type-driven (SemanticClass), not declared in TOML files. The operator explicitly rejected per-datum `[b00t.display]` sections as too verbose.

2. **Isometric > Mermaid**: Mermaid v11 is fragile (syntax errors, version drift). The long-term direction is ledgrrr's `kasuari` constraint solver + isometric glTF/SVG rendering. The isometric view in the admin UI is a Python-generated SVG placeholder — it needs to be replaced with the real kasuari engine.

3. **Capability dispatch, not suffix dispatch**: `b00t opencode` should work without disambiguation. Current fix: symlinks + `DatumType::implies()` hierarchy. Long-term: `provides` field on BootDatum.

4. **Sub-agents via b00t, not bash scripts**: The operator prefers observable, bounded sub-agent delegation over shell scripts. Use the `task` tool for parallel research/dispatch.

5. **Test after every commit**: `just deploy` runs the full pipeline. The operator expects tests to pass before pushing.

6. **b00t sh for system mutations**: Guard-enforced sandboxed shell. Use `b00t sh <cmd>` instead of raw bash for privileged operations.

7. **WSL environment**: No sandbox isolation (unshare fails). Chrome CDP requires `--remote-debugging-port=9222` on the Windows host, relayed through `scripts/cdp-relay.py`.

8. **OODA is a Plan subtype, not a Skill**: The operator corrected the stereotype. Ooda belongs to SemanticClass::Tool (teal rectangle), same class as Plan.

## Architecture Decisions

| Decision | Rationale |
|---|---|
| SemanticClass display system | 9 classes, 26 types derive shape/color/icon. `css_class` is the subsystem animation hook. |
| DatumType::implies() hierarchy | Runtime→Cli, Agent→Runtime, McpServer→Mcp. Eliminates disambiguation prompts. |
| Symlink datums | One canonical file per tool, symlinked into type namespaces. No content duplication. |
| MCP tools MUST include `description` | OpenCode's Zod validator rejects tools without it. Also requires `type:"object"` in inputSchema, strips `$schema`. |
| blessed ecosystem search | 92 curated + 770 community entries. Trust tiers: 🥾blessed > 📋awesome > 📦local. |
| Template-scope errors | JS statements inside object literals pass `node -c` but fail in browser. Only jsdom/CDP catches these. |

2. **Mermaid v11 fragility**: `graph LR` removed, must use `flowchart LR`. `---` separator needed between multi-graph blocks. Considered unsuited for this task — migrate to isometric.

3. **Merge conflicts in format! templates**: The `<<<` markers survive into served HTML because the entire UI is one giant `format!(r#"..."#)` string. The `html_sanity` compile-time tests catch these now.

4. **git hook modifies evidence/satisfies.jsonl**: Causes perpetual dirty state. Marked `skip-worktree` but still blocks merges.

5. **CDP requires Chrome restart**: Can't enable `--remote-debugging-port` on a running Chrome instance. Must launch fresh from PowerShell/WSL.
